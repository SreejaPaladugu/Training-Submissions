Apache Spark is a distributed data processing engine built for big data workloads, designed to run computations in parallel across cores/machines. It uses high-level APIs (DataFrames/SQL) to perform transformations (lazy, optimized) and actions (execute jobs), with a cluster manager and a driver/executor model. Spark is fast because it can keep data in memory, supports efficient query optimization (Catalyst optimizer) and execution planning, and provides libraries for SQL, streaming, machine learning (MLlib), and graph processing, making it a foundation for scalable analytics pipelines.
